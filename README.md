# Muon research blog

Upload the contents of this folder to the GitHub Pages repository root. Article URL: `/blog/muon-eos-en/`. Do not add `.nojekyll`.

Edit `blog/muon-eos-en.md` for prose/math, `assets/style.css` for design, `_includes/*.html` for figures and captions, `index.md` for the homepage, and `_config.yml` for deployment URL/baseurl. Images are in `assets/images/muon/`.

The article has 11 figures, five expandable derivations, an optional warmup view, and a paused scalar-GD animation. Main schematic figures are editable SVGs; their panels stack on small screens. Math uses Kramdown/MathJax; no framework or Node build is needed. The outer package contains an offline MathML preview, plot exports, original sources and reproduction scripts.

Keep existing personal homepage changes when merging. Uploading files through GitHub does not delete obsolete files; remove old unused articles or assets separately.
